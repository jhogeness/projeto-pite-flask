# Situação 2: desenvolvimento

## Código
Está nas pastas `app/` (MVC) e `tests/`, na raiz do repositório.

## Manual de uso
1. Em "Matérias", cadastre uma matéria (ex.: Cálculo).
2. Em "Tarefas", clique em "Nova Tarefa", preencha título, matéria e prazo (opcional) e salve.
3. Use "Alternar Status" para concluir uma tarefa ou voltá-la a pendente.
4. Use "Excluir" para remover (pede confirmação).
5. Use os filtros "Todas", "Pendentes" e "Concluídas" para organizar a lista.
